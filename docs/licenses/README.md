# WebView2 固定版许可

`WebView2-Fixed-License.html` 保留 Microsoft 官方固定版许可的 HTML 正文，取自官方许可接口返回的 `fixedHtml`，取得日期为 2026-10-13：

[Microsoft 官方许可接口](https://developer.microsoft.com/microsoft-edge/api/eula/webview2?locale=en-us&fixed=true)

随 portable 分发的运行组件直接来自微软官方 Fixed Version 下载，整个运行目录及自带第三方 notices 保留。微软运行组件不采用 Spacefold 的 MIT 许可；使用与再分发须遵循该许可。第 2 节列明分发权及要求，第 8 节要求 SmartScreen 用户通知，已在项目 README 与成品使用说明提供。

WebView2 包含 Microsoft Defender SmartScreen，会按[微软隐私声明](https://aka.ms/privacy)及 [Microsoft Edge 隐私说明](https://learn.microsoft.com/en-us/microsoft-edge/privacy-whitepaper#smartscreen)收集和向微软发送最终用户相关信息。
