# 第三方组件与许可

Spacefold 源码使用 MIT；第三方组件各自遵循下列许可。此清单按 Windows x64 的 Cargo 锁定图及 npm 锁文件生成，包含构建/测试依赖，不表示全部组件均进入成品。原始许可证与版权声明在 [THIRD-PARTY-LICENSES.txt](../THIRD-PARTY-LICENSES.txt)。

MPL-2.0 组件未修改，相关源码可通过 Cargo/npm 对应锁定版本取得。随 portable 分发的 Microsoft WebView2 Runtime 另遵循包内微软许可和 notices，不属于 Spacefold 的 MIT 许可。
